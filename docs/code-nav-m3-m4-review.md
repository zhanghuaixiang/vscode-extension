# 代码理解面板 M3 验证与 M4 评估

## M3 自动化验收

- 后台解析：`worker_threads` 承担 AST 工作；切换文件时取消旧任务，并按请求序号与文档版本拒绝旧结果。
- 缓存：URI + 文档内容 SHA-256；切回未修改文件复用结果，手动刷新强制重算。
- 面板：首屏限制入口、关系和节点数量；结构分段分页，模板子树展开时按需请求；函数聚焦只展示本文件静态关系。
- VS Code 1.142.0 扩展宿主测试：20/20 通过，覆盖文件切换、未保存内容、强制刷新、聚焦、worker 取消、过期任务和投影分页。
- 2026-10-16 合成基线：10,000 行 / 377,779 字节 JS，30,001 个节点；worker 返回约 472 ms，首屏投影约 23 ms，预览 108 个节点，测量进程 RSS 约 190 MiB。单次机器测量不是性能承诺，也不代表真实 Vue 深树。

**尚未完成的产品验收**：没有真实项目大文件或未读过样本的开发者，因此不能记录真实首屏交互耗时、阅读任务耗时、正确率及错误断言，也不能声称理解效率提升。试用时按“入口、状态写入、本文件内调用”三类问题，对照无插件/有插件的耗时和正确率；错误断言逐条追溯到证据行。若正确率下降，应先修正导读与路径。

## M4 决策

执行计划将 M4 定义为**单独评审是否进入下一迭代**，本次不把待评估功能并入已验收的离线基础能力。

| 增强项 | 价值与前置条件 | 本次决定 |
| --- | --- | --- |
| Review 本次改动 | 需明确未保存改动、Git diff 与基准版本的来源；行区间映射必须经测试，缺少 diff 时回退文件导读 | 暂缓。先用真实试用确定“改动上下文”是否比文件导读更有帮助 |
| 风险提示 | 仅报告可定位的现象，不将长函数、`console` 或 `v-html` 直接等同漏洞；需约定误报与阈值 | 暂缓。先收集真实代码样本和误报基线 |
| 可选 LLM 分组 | 必须显式授权上传范围、保护源码隐私、标注推测；离线规则分组和跳转保持完整可用 | 暂缓。无模型或请求失败不得影响基础模式 |
| HTML 导出 | 需过滤或转义源码内容，确定快照版本、离线资产与分享边界 | 暂缓。待确认团队确有脱离 VS Code 分享导读的需求 |

下一迭代进入条件：取得至少一组真实陌生文件及试用反馈，为各项写出独立协议与失败回退测试，再单独估算和排期。现有 v1 协议不添加未经验证的风险结论或模型推测。
